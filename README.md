# Box Challenge v0.3 – Pi Edition
Includes 3D dice animation, custom Pi Box icons, 11-language selector, dice switching (+2/+3/+4), AI demo comments, locked New Match during play, personal best, Perfect Game celebration, and Pi SDK authentication scaffold.

Pi authentication requires registration/configuration in the Pi Developer Portal. Real payments are not enabled in this frontend-only build because secure payment flows require backend approval and completion.
